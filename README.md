# ПР-4: Прогнозирование рейтинга игроков

Проект на датасете `players.csv`: сравнение линейной регрессии на полном и сокращённом наборах числовых признаков. Целевая переменная — `overall_rating`.

## Этапы работы

- Разделение данных на train, validation и test.
- Предобработка через `Pipeline` и `ColumnTransformer`: заполнение пропусков медианой и масштабирование.
- Анализ корреляций и удаление избыточных признаков.
- Сравнение моделей по MAE, RMSE и R².
- Анализ остатков и обоснование финального набора признаков.

## Файлы

- `data/players.csv` — исходный датасет.
- `notebooks/PR4_players.ipynb` — код, результаты и выводы.

## Запуск

Установите зависимости:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

Откройте `notebooks/PR4_players.ipynb` в VS Code, выберите Python-ядро и нажмите **Run All**.

MAE и RMSE интерпретируются в баллах рейтинга. Предобработка обучается без использования тестовой выборки.
